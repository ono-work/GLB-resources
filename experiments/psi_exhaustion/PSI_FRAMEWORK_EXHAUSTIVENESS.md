## 1. Formal definition

Notation: `G_3` is the set of games born by day 3 (the option universe), `≤` is the game order, and `F0 = {* (3), ±1 (12), *2 (21)}`. The code numbers games by their index in `verify_v2`.

For `X ⊆ G_3`, `H_L(X) = {g : every right option of g is ≥ some x ∈ X}`. Also:

- `req(x)` is the set of maximal left options of `x`;
- `REQ` is the union of `req` over `T ∪ V_max`;
- `dom L = {q ∈ REQ : q ≤ some l ∈ L}`;
- `V(D) = {x ∈ V_max : req(x) ⊆ ↓D}`.

A **key** is `κ = (world, S, C, E)`. The framework is the union of the families `Ψ(κ)` together with their mirrors.

**0-world** (original class `O0 = {0 ∈ R ∖ L}`):

- `(S, C, E)` is an ordered partition of `F0`, and `T = {0} ∪ S`.
- The pool is `H_L(T ∪ C) ∖ {0}`.

**Z-world** (original class `OZ = {0 ∉ L ∪ R, R ∩ ↓0 ∖ {0} ≠ ∅, * ∈ R ∖ L}`):

- `F = {0} ∪ F0`, with `* ∈ S` and `0 ∈ C` fixed. `(S∖{*}, C∖{0}, E)` is an ordered partition of `{±1, *2}`, and `T = S`.
- The pool is `H_L(T ∪ C) ∖ {0, *}`.

**Members of `Ψ(κ)`** are the pairs `{L | R}` with:

- `L` an antichain of the pool, with `req(T) ⊆ ↓dom L`;
- `R = T ∪ B`, where `B` is an antichain of `V(dom L)` with `B ∩ F = ∅`;
- for every `m ∈ C`: `B ∩ (↓m ∖ {m}) ≠ ∅`;
- for every `m ∈ E`: `B ∩ ↓m = ∅`.

**Safety.** Every member is a canonical form:

- No left option is reversible: each right option of each `l` is `≥ t ∈ T ⊆ R`, or `≥ m > b ∈ R`.
- No right option is reversible: `req(x) ⊆ ↓dom L`.
- `L` and `R` are antichains by construction: `L` and `B` are chosen as antichains, and `V_max ∥ T`.

**Mirrors.** Negation maps `O0 → −O0 = {0 ∈ L ∖ R}` and `OZ → −OZ = {0 ∉ L ∪ R, * ∈ L ∖ R}`.

**Overlap with v5.**

- v5 G1 is exactly `Ψ(0; *±1*2; –; –)`.
- v5 G2 is all of `Ψ(0; *±1; –; *2)`, plus the part of `Ψ(0; *±1; *2; –)` with `L ⊆ H_L([0, *, ±1])`.
- The ledger family N2 is the complement: the same key with `L ⊄ H_L([0, *, ±1])`.

## 3. Partition argument

1. **The key is a function of the pair.** For a pair `{L | R}` (`rekey` in the audit):
   - the world is 0 if `0 ∈ R ∖ L`;
   - it is Z if `0 ∉ L ∪ R`, `R` has an element strictly below 0, and `* ∈ R ∖ L`;
   - `S = R ∩ F0`;
   - `C` is the set of `m ∈ F ∖ S` with an element of `R` strictly below `m`;
   - `E` is the rest.

   So the 36 families are pairwise disjoint. Every framework member lies in exactly one of them, namely the family of its own key.

   *Machine check U3:* 100 random members of every key (3500 in total) re-key to their own key. Their negations re-key to `None`, so they are not originals of any key.
2. **The enumeration is complete.** The key is determined by the map `F0 → {S, C, E}` (0-world) or `{±1, *2} → {S, C, E}` (Z-world). The audit enumerates all such maps (U1).
3. **The hypotheses hold on every key** (U2): `T` is an antichain, `V_max ∥ T`, the pool condition holds, `0 ∉ pool`, and in the Z-world `* ∉ pool`. So every key, including the 22 remaining ones, is admissible. No key is empty by hypothesis failure.
4. **Mirrors** are counted once each, as 2 × the original. The classes `O0`, `OZ`, `−O0` and `−OZ` are pairwise disjoint (separated by 0 and by `*`). Negation is an involution that preserves canonical forms.
5. **v5 is not counted twice** (U4).
