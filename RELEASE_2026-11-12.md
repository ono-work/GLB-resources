## Fresh-clone test

A fresh `git clone -b snapshot-2026-11-12` of the local repository was made on 2026-11-20
and `python3.11 scripts/verify_all.py` was run in it:

- result: `ALL PUBLIC ARTIFACT CHECKS PASSED` in 63 s (full output in `VERIFICATION_REPORT.md`);
- `FILE INTEGRITY VERIFIED (344 files)`: the line-ending fix holds in a fresh checkout
  (`git ls-files --eol` shows `i/crlf w/crlf attr/-text` for the five files);
- the post-GPW audit chain ran on the copy under `generated/` and `git status` was clean
  afterwards, so the verification relies on no untracked local file and modifies nothing.

Before this version, a fresh clone of `gpw26-v1.0` failed at the first step
(`checksum mismatch: data/gub/game_export/games.csv`).
