# 一般安全直積 IP 継続実験（日本語報告）

## 結論

既存の一般安全直積 0--1 整数計画を変更せず、監査済み `z=95` 解とその反転像を完全 MIP start として Gurobi 10.0.0 で最大化した。その結果、単一runで

\[
z^\star=98
\]

が `OPTIMAL`（incumbent 98、best bound 98、MIP gap 0）と証明された。保存解は二つの独立検証経路で正本データから再検査され、ともに通過した。従って、この一般IPが表す安全単一直積の最適値は98であり、

\[
g(4)\ge 2^{98}=316912650057057350374175801344
\]

を得る。これは従来の `z=95` 単一直積の8倍である。

## 最適解

\[
T_L=[0, 3, 12, 21],\qquad T_R=[1, 6, 16].
\]

`A` と `B` の export ID は [best_solution.json](../../experiments/lower_bound/general_safe_rectangle_ip_followup/best_solution.json) に完全保存した。サイズは

\[
|A|=82,\quad |B|=23,\quad |T_L|=4,\quad |T_R|=3,
\]

従って

\[
(82-4)+(23-3)=98.
\]

## 実験経過

`z\ge100,99,98,97,96` の各実行可能性runは、それぞれ7200秒で解を発見せず時間切れとなった。これらは `TIME_LIMIT_UNKNOWN` であり、個別の不存在証明には用いない。その後の一般最大化runでは、MIP start `z=95` が受理され、約296秒で `z=98` を発見した。約11634秒で上界が98まで閉じ、大域最適性が証明された。

複数seedや別の `z\ge99` 証明runは不要になった。一般最大化の同一runが `z=98` の実行可能性と `z\le98` の上界を同時に証明したためである。
